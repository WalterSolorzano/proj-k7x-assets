Ensambla y presenta:
1. `npm run build` para componer `paginas/` desde `secciones/_sections.json`.
2. Revisa la página ensamblada y corrige desajustes entre secciones (espaciado, ritmo, color).
3. Delega la presentación: capturas con `npm run capture` y video con `npm run video`.
4. Resume en una línea por página y actualiza `PROYECTO.md`.
